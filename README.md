# ختمتنا — متابعة ختم القرآن الكريم

موقع بسيط لمتابعة ختم القرآن الكريم بين الزوجين (سالم ونسمة)، يعمل على أي جهاز ويتزامن فورياً عبر قاعدة بيانات Supabase.

## المزايا
- تسجيل القراءة على مستوى **الصفحة** (604 صفحة، ترقيم مصحف المدينة)
- عرض السور الـ114 مع نسبة الإنجاز وتاريخ اكتمال كل سورة
- عرض الأجزاء الـ30 وتحديد جزء كامل بضغطة واحدة
- زر سريع «قرأت الصفحة التالية» وزر «وصلت إلى صفحة …»
- وِرد يومي قابل للتعديل لكل شخص + عدّاد الأيام المتواصلة 🔥
- مقارنة ودّية بين الزوجين + رسم بياني لآخر 7 أيام
- ختمات متعددة مع سجل بتاريخ بداية ونهاية كل ختمة
- التحديثات تظهر فوراً على جهاز الطرف الآخر (Realtime)

## التقنيات
Vite + React · Supabase (Postgres + Realtime) · بدون أي مكتبات واجهة إضافية

## الرفع على Vercel (خطوة بخطوة)

### الطريقة 1: من GitHub (الأفضل)
1. أنشئ مستودعاً جديداً على GitHub وارفع هذا المجلد إليه:
   ```bash
   git init
   git add .
   git commit -m "ختمتنا"
   git branch -M main
   git remote add origin https://github.com/USERNAME/quran-khatma.git
   git push -u origin main
   ```
2. ادخل إلى [vercel.com](https://vercel.com) → **Add New → Project** → اختر المستودع.
3. سيتعرف Vercel تلقائياً على Vite. اضغط **Deploy** فقط.
4. بعد دقيقة يظهر الرابط، مثل: `https://quran-khatma.vercel.app` — أرسله لزوجتك وافتحاه على الهاتف.

### الطريقة 2: من الطرفية (بدون GitHub)
```bash
npm install
npm install -g vercel
vercel          # اتبع الأسئلة واضغط Enter على الخيارات الافتراضية
vercel --prod   # للرفع النهائي
```

### متغيرات البيئة (اختياري)
رابط Supabase والمفتاح العام موجودان داخل `src/supabase.js` ويعملان مباشرة.
إذا أردت تغييرهما لاحقاً دون تعديل الكود، أضف في Vercel → Settings → Environment Variables:
- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`

## قاعدة البيانات
المشروع على Supabase جاهز ومجهّز (الاسم: `quran-khatma`). الجداول:
- `readers` — القارئان (الاسم، اللون، الوِرد اليومي، صيغة المخاطبة)
- `khatmas` — الختمات (رقم الختمة، تاريخ البداية والاكتمال)
- `page_reads` — الصفحات المقروءة في كل ختمة مع وقت القراءة

ملف `supabase/schema.sql` يحتوي على كامل الجداول إذا أردت إعادة إنشائها في مشروع آخر.

> **ملاحظة أمنية:** الموقع بلا كلمة سر (باختياركما)، فأي شخص يحصل على الرابط يستطيع التسجيل باسم أحدكما. لا تنشروا الرابط علناً. إذا أردتما حماية أقوى لاحقاً يمكن إضافة رمز PIN أو تسجيل دخول.
